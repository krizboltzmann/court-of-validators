Court of Validators is a futuristic browser game inspired by GenLayer, where players act as AI governance validators and make consensus decisions on autonomous agent disputes, misinformation cases, DAO conflicts, and ethical dilemmas.

Built with Next.js, TypeScript, TailwindCSS, and Framer Motion, the game combines cyberpunk aesthetics with fast-paced decision gameplay, XP progression, and randomized AI governance scenarios.

Features:

* 30+ unique governance and AI dispute cases
* XP and validator rank system
* Futuristic holographic UI
* GenLayer branding and mascot integration
* Responsive browser gameplay
* Smooth animations and consensus effects

Inspired by the future of decentralized AI governance and “Trust Infrastructure for the AI Age.”
